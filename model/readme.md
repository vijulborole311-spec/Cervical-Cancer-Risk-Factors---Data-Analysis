# Cervical Cancer Risk Factors - Data Analysis

## 📌 Project Overview

This project focuses on exploring and analyzing a dataset containing risk factors related to cervical cancer.

The dataset includes information about demographic characteristics, sexual behavior, pregnancies, smoking habits, hormonal contraceptive usage, IUD usage, and diagnostic results.

The initial analysis is performed using Python with Pandas and NumPy.
